# SoilWaterCM 用户手册

## 1. 系统概述

SoilWaterCM 是一个水土保持监测管理系统，提供遥感数据处理、水土保持分析、异常预警等功能。

### 1.1 主要功能

- **项目管理**：管理监测项目、监测期
- **影像管理**：上传、管理遥感影像
- **数据处理**：影像预处理、镶嵌
- **信息提取**：植被覆盖度反演、土壤侵蚀计算、扰动图斑提取、水保措施解译
- **综合评价**：合规性评价、风险性评价
- **异常预警**：异常识别、预警推送、派单处置
- **监测报告**：报告生成、备案
- **数据看板**：数据统计、可视化

### 1.2 用户角色

| 角色 | 权限 |
|------|------|
| Admin | 系统管理、用户管理、所有项目操作 |
| Monitor | 监测操作、数据处理、报告生成 |
| Leader | 查看数据、审批报告 |

## 2. 快速开始

### 2.1 登录系统

1. 访问系统地址：http://localhost:8080
2. 输入用户名和密码
3. 点击"登录"按钮

### 2.2 创建项目

1. 进入"项目管理"页面
2. 点击"新建项目"按钮
3. 填写项目信息：
   - 项目编码（唯一）
   - 项目名称
   - 责任区域
   - 中心位置（经度、纬度）
   - 项目范围（绘制或上传 GeoJSON）
4. 点击"保存"按钮

### 2.3 上传影像

1. 进入"影像管理"页面
2. 点击"上传影像"按钮
3. 选择影像文件（支持 GeoTIFF、IMG 等格式）
4. 填写影像信息：
   - 所属项目
   - 所属监测期
   - 影像类型
   - 传感器类型
5. 点击"上传"按钮
6. 系统自动进行质量检查

### 3.4 信息提取

#### 3.4.1 植被覆盖度反演

**功能**：基于遥感影像计算植被覆盖度

**原理**：NDVI 二分法
- NDVI = (NIR - Red) / (NIR + Red)
- FVC = (NDVI - NDVIsoil) / (NDVIveg - NDVIsoil)

**步骤**：
1. 选择影像
2. 设置参数：
   - NDVIsoil（裸土NDVI值，默认0.2）
   - NDVIveg（纯植被NDVI值，默认0.8）
3. 提交计算任务
4. 查看结果：
   - FVC 栅格图
   - FVC 分级统计（低、中、高）

#### 3.4.2 土壤侵蚀计算

**功能**：基于 USLE 模型计算土壤侵蚀

**原理**：USLE 模型
- A = R × K × L × S × C × P
- R：降雨侵蚀力因子
- K：土壤可蚀性因子
- L：坡长因子
- S：坡度因子
- C：植被覆盖因子
- P：水保措施因子

**步骤**：
1. 选择监测期
2. 设置参数：
   - 降雨数据路径
   - 是否使用 GRASS（LS因子）
   - 是否使用 SAGA（K因子）
3. 提交计算任务
4. 查看结果：
   - 侵蚀模数栅格图
   - 侵蚀分级图
   - 各级侵蚀面积统计

#### 3.4.3 扰动图斑提取

**功能**：提取地表扰动图斑

**方法**：变化检测 + 分类

**步骤**：
1. 选择前后两期监测期
2. 设置参数：
   - 变化检测阈值
   - 最小图斑面积
   - 是否使用 OTB 分类
3. 提交提取任务
4. 查看结果：
   - 扰动图斑矢量图
   - 各类扰动面积统计

#### 3.4.4 水保措施解译

**功能**：解译水保措施类型

**措施类型**：
- 梯田
- 淤地坝
- 林草措施
- 工程措施

**步骤**：
1. 选择监测期
2. 设置参数：
   - 是否使用 AI 模型
   - 模型路径（如使用AI）
3. 提交解译任务
4. 查看结果：
   - 措施矢量图
   - 各类措施数量和面积

### 3.5 综合评价

#### 3.5.1 评价方法

**AHP 层次分析法**：
- 构建判断矩阵
- 计算权重
- 一致性检验（CR < 0.1）

**熵权法**：
- 计算信息熵
- 计算权重

**组合权重**：
- 综合 AHP 和熵权法结果

#### 3.5.2 评价流程

1. 选择监测期
2. 设置评价参数：
   - 是否使用 AHP
   - 是否使用熵权法
   - AHP 判断矩阵
3. 提交评价任务
4. 查看结果：
   - 合规性得分和等级
   - 风险性得分和等级
   - 各指标权重和得分

### 3.6 异常预警

- **违规扰动**：在禁止区域发生扰动

- **措施损毁**：水保措施被破坏
- **InSAR形变**：地表形变异常

#### 3.6.2 异常处置流程

1. 系统自动识别异常

## 7. 常见问题

### Q1：影像上传失败？

**可能原因**：
- 文件格式不支持
- 文件过大
- 网络问题

**解决方法**：
- 检查文件格式（支持 GeoTIFF、IMG）
- 检查文件大小（建议 < 500MB）
- 检查网络连接

### Q2：任务执行失败？

**可能原因**：
- 输入数据问题
- 参数设置错误
- 系统资源不足

**解决方法**：
- 查看错误信息
- 检查输入数据
- 调整参数设置
- 联系管理员

### Q3：报告生成失败？

**可能原因**：
- 模板文件缺失
- 数据不足

**解决方法**：
- 检查模板文件
- 确保监测期有足够数据

### Q4：外部工具调用失败？

**可能原因**：
- 工具未安装
- 工具路径配置错误

**解决方法**：
- 联系管理员安装工具
- 检查工具配置
